# Sleep de Game Boy of de muziekspeler met de muis (niet op een knop), of pak het greepje (•••) bovenaan.

# Toetsenbord: Tab naar het greepje, pijltjestoetsen verplaatsen (Shift = grotere stappen), Esc = terug.
# De plek wordt onthouden. Knop rechtsonder: alles terugzetten.
